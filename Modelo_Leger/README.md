# 🔱 Modelo predictivo de la prueba física Leger 🔱
## **Objetivo**
Por medio del aprendizajre supervisado predecir valores/resultados de la prueba física
de Leger basados en datos etiquetados, en este caso: Salto largo, 30 m Lanzados (s), IMC,
IA (Indice de Agilidad) y PR (Potencia Relativa).

### 🔱 Verificar Python & Git
```
> python --version
> git --version
```
